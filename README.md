## Entregables

Entre los recursos que se encuentran actualmente en este repositorio están:

### Tareas:
- **Tarea 01**. Introducción al cómputo concurrente.
- **Tarea 02**. Problemas Clásicos.
- **Tarea 03**. Objetos Concurrentes y `volatile`.

### Prácticas:
- **Práctica 01**. Repaso de Java e introducción a la programación multihilos.
- **Práctica 02**. Exclusión Mutua: Locks y Pools en Java.
- **Práctica 03**. Exclusión Mutua: Cándados Clásicos y el Modelo de Memoria de Java (JMM).
- **Práctica 04**. Spinlocks y algunas primitivas.
