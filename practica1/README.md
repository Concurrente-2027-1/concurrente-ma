# Práctica 1: Repaso de Java e introducción a la programación multihilos.

Implementación de los ejercicios correspondientes a la **Práctica 01** de la materia de **Cómputo Concurrente**.

## Contenido

### `src/`

Contiene las implementaciones en **Java** de los ejercicios solicitados en la práctica.

### `docs/`

Contiene el documento **`Practica01.pdf`**, donde se presentan las respuestas a los ejercicios de la práctica.

## Ejecución
Para la ejecución de los programas, se debe contar con Java 21 LTS.
