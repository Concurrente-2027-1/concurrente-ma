# Práctica 4: Spinlocks y algunas primitivas

Implementación de los ejercicios correspondientes a la **Práctica 04** de la materia de **Cómputación Concurrente**.

## Contenido

### `src/`

Contiene las implementaciones en **Java** de los ejercicios solicitados en la práctica.

### `docs/`

Contiene el documento **`Practica04.pdf`**, donde se presentan las respuestas a los ejercicios de la práctica.

## Ejecución
Para la ejecución de los programas, se debe contar con Java 21 LTS.
