# Práctica 2: Exclusión Mutua: Locks y Pools en Java

Implementación de los ejercicios correspondientes a la **Práctica 02** de la materia de **Cómputo Concurrente**.

## Contenido

### `src/`

Contiene las implementaciones en **Java** de los ejercicios solicitados en la práctica.

### `docs/`

Para la ejecución de los programas, se debe contar con Java 21 LTS.
